## Em destaque · MercadoÁgil

O que acontece com o estoque quando um cliente cancela um pedido? No MercadoÁgil, o cancelamento devolve os itens ao estoque. Na confirmação, o serviço verifica se há unidades de todos os produtos antes de dar baixa. Implementei esse fluxo em JavaScript e escrevi testes para as regras de pedidos.

O projeto roda no terminal e inclui dados de exemplo para experimentar compras, cupons e cancelamentos. [Ver o MercadoÁgil e os testes](https://github.com/devpedroamorim/mercadoagil-complete)
